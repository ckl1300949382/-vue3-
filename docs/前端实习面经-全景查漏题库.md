## 一、TypeScript 专项（P0，简历写了就跑不掉）

### 1. TS 解决什么问题？JS 不好在哪？
- JS 是动态类型，错误要到**运行时**才暴露；TS 在**编译期**就能发现类型不匹配
- 附带收益：IDE 自动补全准、重构有信心、类型本身就是文档
- 【结合项目】自建 `types/` 目录定类型契约：`BizResult<T>` 统一后端响应结构、`PageData<T>` 分页结构，接口函数全有参数/返回类型注解

### 2. interface 和 type 的区别？
- 大部分场景通用。interface：可 `extends`、可**声明合并**（同名自动合并）；type：支持**联合类型、交叉类型、条件类型**等类型运算
- 实习答法："对象结构用 interface，类型运算用 type"，能说出这句就够
- 【结合项目】你用过交叉：`RegisterDTO & UpdateUserDTO` 合并表单类型——主动讲出来

### 3. 泛型是什么？为什么需要？
- 类型版的"参数"：把类型作为变量传进去，一份逻辑适配多种类型，还保住类型检查
- 【结合项目】`BizResult<T>`：T 是 UserVO 时 data 就是用户对象，T 是统计对象时 data 就是统计字段——不用为每种响应写一套定义
- 追问"泛型在函数里怎么用"：`function first<T>(arr: T[]): T | undefined`

### 4. 常用工具类型说几个？
- `Partial<T>`：全变可选（更新表单场景）；`Pick<T, K>`：挑字段；`Omit<T, K>`：排除字段；`Record<K, V>`：键值对映射
- 【结合项目】mock 映射表就用 `Record<string, BizResult<unknown>>`

### 5. any 和 unknown 区别？
- any：放弃检查，怎么用都不报错——**等于关掉 TS**
- unknown：安全的 any——赋值随便，但**使用前必须收窄**（typeof 判断等）
- 实习答法："未知来源的数据用 unknown 收窄后再用，不用 any"

### 6. 类型收窄（narrowing）知道吗？
- TS 根据判断条件自动缩小类型范围：`typeof x === 'string'` 后 x 就是 string；`in` 判断字段存在；可辨识联合（对象里带 kind/type 字段）
- 【结合项目】`if (store.userInfo?.role === 'admin')` 就是收窄——userInfo 从"可能没有"收窄到"确定存在且是管理员"

### 7. 枚举 enum 和字面量联合类型怎么选？
- `type Role = 'admin' | 'user'` 更轻，打包后消失；enum 会生成真实对象
- 【结合项目】角色状态用字面量联合即可，还省一次运行时开销

## 二、Vue 3 进阶（P0）

### 1. Vue 3 响应式原理？和 Vue 2 区别？
- Vue 3 用 **Proxy** 拦截对象读写：get 时收集依赖，set 时触发更新
- Vue 2 的 `Object.defineProperty` 缺陷：**新增/删除属性监听不到**（所以要 `Vue.set`）、**数组索引赋值监听不到**
- Proxy 直接代理整个对象，13 种拦截方法，天然解决上面两个问题
- 加分句："还有weakMap 依赖收集、effect 副作用这些实现细节，我看过概念但没深入源码"——诚实且留追问余地

### 2. 生命周期说一下？你在哪一步请求数据、清理东西？
- setup 代替 beforeCreate/created → onMounted（挂载完，可拿 DOM/发请求）→ onUpdated → onUnmounted（卸载前，做清理）
- 【结合项目】ECharts：onMounted 初始化实例 + window resize 监听；**onUnmounted 里先 removeEventListener 移除监听、再 dispose() 销毁实例**——不做就内存泄漏。这是你简历写过的点，必被追问"为什么要 dispose"

### 3. watch 和 watchEffect 区别？
- watch：**显式指定**监听源，回调能拿新旧值，惰性（变化才执行）
- watchEffect：立即执行一次，**自动收集**函数内用到的响应式依赖
- 选型："需要旧值或精确控制就用 watch，一堆依赖联动一个副作用用 watchEffect 省事"

### 4. 组件上的 v-model 原理？
- 就是语法糖：`:modelValue="x"` + `@update:modelValue="x = $event"`
- 【结合项目】UserFormDialog 弹窗没直接用 v-model，而是 `:model-value="dialogVisible"` + `@close` 让**父组件改状态**——因为弹窗显隐的控制权必须在父组件手里，这是单向数据流。面试主动讲这个设计决策，非常加分

### 5. 什么是单向数据流？为什么子组件不能改 props？
- 数据从父流向子单向流动；子改 props 会让数据源不唯一，排查问题就找不到谁改的
- 正确姿势：子组件 emit 事件，父组件改数据；props 只读
- 【结合项目】UserTable 是纯展示组件，edit/delete 全 emit 给父层处理

### 6. nextTick 是干嘛的？
- Vue 的 DOM 更新是**异步批量**的（改一次数据，DOM 不会立刻变）；nextTick 在 DOM 更新完成后执行回调
- 场景：改完数据立刻要读 DOM（如弹窗打开后聚焦输入框）

### 7. computed 为什么有缓存？
- 依赖不变就返回上次结果，不重算；methods 每次渲染都执行
- 【结合项目】`isLoggedIn = computed(() => !!token.value)`——token 不变就不重复求值

### 8. keep-alive 了解吗？
- 缓存组件实例，切走不销毁、切回不重建；配合 activated/deactivated 钩子
- 场景：列表页 → 详情页 → 返回，列表不用重新请求

### 9. 路由守卫有哪几种？你的权限怎么做的？
- 全局（beforeEach）、路由独享（beforeEnter）、组件内（onBeforeRouteEnter）
- 【结合项目】meta 打标（requestAdmin/requestUser/requestGuest）+ beforeEach 统一判断；必追问点：**前端权限是体验层，真正安全靠后端接口鉴权**——这句话必须会说

### 10. Pinia 和 Vuex 区别？为什么选 Pinia？
- 去掉 mutations（只有 state/getters/actions）、TS 支持好、天然支持组合式写法、模块自动拆分不用嵌套
- 【结合项目】`pinia-plugin-persistedstate` 持久化 token——刷新不丢登录态

### 11. setup 里为什么 ref 要 .value，模板里又不用？
- 基本类型没法被 Proxy 代理，所以包成 `{ value }` 对象做响应式；模板编译时会自动解包

### 12. 组件通信方式全家桶（实习能报出 5 种就赢）
- props/emit、v-model、provide+inject（跨层）、Pinia（全局）、$attrs 透传、ref 拿实例（兜底）
- 【结合项目】选型逻辑：父子用 props/emit，登录态全局共享用 Pinia

## 三、JavaScript 核心（P1）

### 1. 事件循环（Event Loop）——必考，必须会画流程
- 顺序：**同步代码 → 清空所有微任务 → 取一个宏任务 → 再清微任务 → 循环**
- 微任务：Promise.then/catch/finally、queueMicrotask；宏任务：setTimeout、setInterval、DOM 事件、I/O
- 经典题（自己推一遍再背）：
  ```js
  console.log(1)
  setTimeout(() => console.log(2))
  Promise.resolve().then(() => console.log(3))
  console.log(4)
  // 输出：1 4 3 2 —— 同步(1,4) → 微任务(3) → 宏任务(2)
  ```

### 2. 数据类型有哪些？怎么判断？
- 7 原始（number/string/boolean/undefined/null/symbol/bigint）+ Object
- typeof 的坑：`typeof null === 'object'`（历史 bug）；判断数组用 `Array.isArray()`
- 精确判断类型：`Object.prototype.toString.call(x)`

### 3. == 和 === 区别？举一个 == 的坑
- == 会隐式转换；=== 严格相等
- 经典坑：`0 == ''` true、`null == undefined` true、`'1' == 1` true
- 实习答法："实际代码一律 ===，我项目里判断都是严格相等"

### 4. 深拷贝和浅拷贝？
- 浅拷贝（`...`展开、Object.assign）：只复制第一层，嵌套对象还是引用
- 深拷贝：`JSON.parse(JSON.stringify(obj))` 的缺陷——**函数/undefined 丢失、循环引用报错、Date 变字符串**；`structuredClone()` 原生方案；手写递归见手写题部分

### 5. 原型链是什么？
- 对象通过 `__proto__` 连到构造函数的 `prototype`，一层层往上找属性，尽头是 null
- `instanceof` 原理：沿原型链找构造函数的 prototype 能不能找到

### 6. this 指向规则？
- 谁调用指向谁（隐式）→ new 调用指向新对象 → call/apply/bind 显式指定 → **箭头函数没有自己的 this，用定义处外层的 this**
- 前端最实用的一条：定时器/回调里要用外层 this，就写箭头函数

### 7. 防抖和节流的区别？（简历写了 useDebounce，必问）
- 防抖：事件停止触发 **delay 后**才执行一次——"等你说完我再动手"。场景：搜索框输入
- 节流：**一段时间内最多执行一次**——"你再急我也按频率来"。场景：滚动监听、按钮防连点
- 【结合项目】搜索用户列表用了防抖：停止输入 500ms 才发请求，避免打爆接口

### 8. ES6+ 常用特性报菜名（挑熟的讲）
- 解构赋值、展开运算符、模板字符串、可选链 `?.`、空值合并 `??`、箭头函数、let/const、模块化 import/export
- 【结合项目】`store.userInfo?.role === 'admin'`——可选链防 null 报错，顺手就能举

### 9. 作用域和闭包（已有文档讲过闭包定义，这里补追问）
- 追问"闭包有什么坏处"：被引用的变量不会回收，滥用可能内存泄漏
- 追问"闭包用在哪"：防抖的 timer、私有变量、柯里化

## 四、浏览器 / 网络 / 安全（P1）

### 1. Cookie / localStorage / sessionStorage 三兄弟
| | Cookie | localStorage | sessionStorage |
|---|---|---|---|
| 容量 | ~4KB | ~5MB | ~5MB |
| 随请求发送 | 是（自动带） | 否 | 否 |
| 过期 | 可设 | 永久 | 关标签页就没 |
- 【结合项目】token 存 localStorage（Pinia 持久化插件自动同步）
- 必追问"token 放 localStorage 会不会被 XSS 偷"：会，所以要防 XSS（见安全题）；cookie 方案有 CSRF 风险但可配 SameSite——能讲出**两种方案的权衡**就赢了

### 2. 常见 HTTP 状态码（对着你的项目背）
- 200 成功；301 永久重定向；304 协商缓存命中；400 参数错误；**401 未认证（登录过期）**；403 无权限；404 找不到；500 服务器错误；502 网关错误
- 【结合项目】401 全流程：响应拦截器捕获 → logout 清登录态 → 跳登录页 → 提示"登录过期"。面试官最爱顺着 401 问"你前端怎么处理的"

### 3. GET 和 POST 区别？
- 语义：GET 获取（参数在 URL、可缓存、幂等）；POST 提交（参数在 body）
- 【结合项目】9 个接口就是 RESTful 风格：GET 查列表、POST 新增、PUT 更新、DELETE 删除——能报出这套语义就是加分

### 4. 强缓存和协商缓存？
- 强缓存：`Cache-Control: max-age` 内**不发请求**直接用本地
- 协商缓存：过期后带 ETag/Last-Modified 问服务器，没变返回 **304** 继续用
- 加分句："Vite 打包文件名带 hash，内容变了文件名就变，天然解决更新问题"

### 5. XSS 是什么？怎么防？
- 攻击者把恶意脚本注入页面执行。分存储型（存进数据库）、反射型（藏在 URL）
- 防御：**渲染用户输入时不信任、不拼接 HTML**（Vue 默认转义插值）、输入过滤、CSP
- 【结合项目】用户名/邮箱是用户输入，表格渲染用 `{{ }}` 插值（自动转义），没用 v-html

### 6. CSRF 是什么？和 XSS 区别？
- CSRF：借用户的登录态，在第三方页面**冒充用户发请求**；XSS 是偷数据/执行脚本
- 防御：SameSite cookie、CSRF Token、验证 Referer

### 7. HTTPS 解决什么问题？
- HTTP 明文传输可被窃听/篡改；HTTPS = TLS 加密 + 证书验证服务器身份
- 说得出"非对称交换密钥、对称加密传数据"即可，不用背握手细节

### 8. 同源策略和 CORS（已有文档有，补一句追问）
- 追问"为什么 CORS 拦截的是响应而不是请求"：请求其实发出去了（服务器可能已执行），是浏览器把**响应**扣下了——能说出这句说明真理解
- 【结合项目】带 Authorization 头的请求是复杂请求，会先发 OPTIONS 预检——你在 Network 里见过

## 五、HTML / CSS（P2，实习考得浅）

### 1. 盒模型？box-sizing 干嘛的？
- content-box：宽高只算内容；border-box：宽高含 padding+border
- 实习答法："项目里一般全局设 `* { box-sizing: border-box }`，写布局不用心算"

### 2. BFC 是什么？怎么触发？干嘛用？
- 独立的渲染区域，内部布局不影响外部
- 触发：`overflow: hidden`、`display: flow-root`、浮动元素、绝对定位
- 用途：**清除浮动**、防止 margin 合并

### 3. 选择器优先级？
- `!important` > 行内样式 > id > class/伪类/属性 > 标签；同级看书写顺序
- 说得出权重计算 (id, class, tag) 更好

### 4. 元素水平垂直居中，说三种方法
```css
/* 1. flex（首选） */
.parent { display: flex; justify-content: center; align-items: center; }
/* 2. grid */
.parent { display: grid; place-items: center; }
/* 3. absolute + transform（子元素尺寸未知也能用） */
.child { position: absolute; left: 50%; top: 50%; transform: translate(-50%, -50%); }
```

### 5. display:none / visibility:hidden / opacity:0 区别？
- display:none：不占位、不响应事件、触发重排
- visibility:hidden：占位、不响应事件
- opacity:0：占位、**响应事件**（可配合做透明遮罩）

### 6. 重排（reflow）和重绘（repaint）？
- 重排：几何属性变了（宽高、位置）→ 重新计算布局，**开销大**；重绘：只变外观（颜色）→ 重画
- 规避：批量改样式、用 transform 代替 top/left 动画（transform 不触发重排）

### 7. flex: 1 是什么意思？
- `flex-grow: 1; flex-shrink: 1; flex-basis: 0%` 的缩写——占满剩余空间

## 七、工程化（P2）

### 1. Vite 为什么快？和 webpack 区别？
- 开发时 Vite 基于浏览器**原生 ESM 按需编译**：请求哪个模块编译哪个；webpack 启动要全量打包依赖图
- 依赖预构建用 esbuild（Go 写的）比 JS 工具链快一个量级
- 生产构建 Vite 用 Rollup——"开发快靠 ESM，构建稳靠 Rollup"

### 2. Git 高频操作 + 两个概念题
- 日常：`git pull` → 新分支开发 → `git add`/`commit` → `push` → 提 PR
- merge vs rebase：merge 保留分叉历史；rebase 把提交"搬到"目标分支后面，历史线性
- reset vs revert：reset 删历史（公共分支**不能**用）；revert 反向提交新记录，安全
- 【结合项目】项目用 GitHub Actions 自动部署：push 到 master 自动 build 并发布到 Pages——CI/CD 概念能挂上

### 3. ESLint 和 Prettier 区别？
- ESLint 管代码**质量**（未使用变量、错误写法）；Prettier 管**格式**（缩进、引号）
- 【结合项目】项目配了 oxlint + eslint 双跑，lint 通过才准提交——提一句说明你有工程规范意识

## 八、手写题（P2，每天练一道保持手感）

### 1. 节流（防抖已有文档）
```js
function throttle(fn, interval = 500) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= interval) {
      last = now
      fn.apply(this, args)
    }
  }
}
```

### 2. 深拷贝（简版，能处理循环引用更佳）
```js
function deepClone(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj
  if (map.has(obj)) return map.get(obj)          // 循环引用：直接返回缓存
  const res = Array.isArray(obj) ? [] : {}
  map.set(obj, res)
  for (const key of Object.keys(obj)) {
    res[key] = deepClone(obj[key], map)
  }
  return res
}
```

### 3. 手写 Promise.all（核心是计数）
```js
function promiseAll(promises) {
  return new Promise((resolve, reject) => {
    const results = []
    let count = 0
    promises.forEach((p, i) => {
      Promise.resolve(p).then((val) => {
        results[i] = val                          // 按原顺序放结果
        if (++count === promises.length) resolve(results)
      }, reject)                                  // 任何一个失败立即 reject
    })
  })
}
```

### 4. 数组扁平化
```js
function flatten(arr) {
  return arr.reduce((acc, cur) =>
    Array.isArray(cur) ? acc.concat(flatten(cur)) : acc.concat(cur), [])
}
```
