## 项目经历

### 【项目一】可视化用户管理平台（个人项目）｜ 2026.05 - 2026.08

> **技术栈**：Vue 3 + TypeScript + Composition API + Pinia + Vue Router + Element Plus + Axios + ECharts + Express
> **在线访问**：<https://ckl1300949382.github.io/-vue3-/>

- **独立开发并上线**：配置 hash 路由与相对路径构建，经 GitHub Actions 自动构建部署至 GitHub Pages，可在线访问
- **分层架构与类型安全**：按 api / store / router / views 分层组织代码；自建 types/ 类型契约（BizResult\<T\> 统一响应、PageData\<T\> 分页结构），覆盖用户管理与统计共 **13 个**接口调用，全程类型约束
- **登录鉴权与权限控制**：Pinia 持久化登录态，刷新不丢失；路由全局守卫按 route.meta 实现游客/用户/管理员三级权限，未登录或越权自动提示并跳转，管理员路由懒加载
- **组件重构与逻辑复用**：将 **325 行**上帝组件拆为 UserTable、UserFormDialog（新增/编辑共用）、UserManage（组装层，脚本仅 **38 行**）三组件；另抽离 **5 个**组合式函数（useUserManage、useDebounce、usePage）复用高频逻辑
- **请求层封装**：封装 Axios 实例，拦截器统一注入 Token、解包统一响应并集中报错，401 自动清除登录态跳转登录页，页面无需重复处理异常
- **数据可视化**：集成 **4 个** ECharts 图表（注册趋势、角色分布、状态分布、月度注册），组件销毁时释放实例与监听，避免内存泄漏
- **前后端闭环**：配合 Express + JWT 后端完成 9 个接口联调（学习用途）
