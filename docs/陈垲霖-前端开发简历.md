## 💼 项目经历

### 【项目一】可视化用户管理平台（个人项目）｜ 2026.05 - 2026.08

> **技术栈**：Vue 3 + TypeScript + Composition API + Pinia + Vue Router + Element Plus + Axios + ECharts + Express  
> **在线访问**：<https://ckl1300949382.github.io/-vue3-/>

- **架构设计**：按「接口层 / 状态层 / 路由层 / 视图层」四层架构组织代码，自建 `types/` 类型契约目录，定义 `DTO/VO` 分离、`BizResult<T>` 泛型响应包、`PageData<T>` 分页结构，实现 API 调用全链路类型安全，覆盖 9 个业务接口
- **登录鉴权**：基于 Pinia + localStorage 实现登录态持久化，刷新不丢失用户身份；通过 Vue Router 全局前置守卫 + `route.meta` 字段完成角色权限控制，管理员路由使用懒加载切分代码包，普通用户无权限访问自动重定向
- **大组件重构**：用户管理模块采用「业务层 - 列表层 - 表单层」三段式重构：抽出 `useUserManage` composable 封装分页、模糊搜索、增删改查逻辑；将 326 行上帝组件拆分为 `UserTable`（表格展示）+ `UserFormDialog`（新增/编辑共用弹窗）+ 胶水层 `UserManage`（≈60 行），新增与编辑复用同一份表单，减少 **40%** 模板重复代码
- **请求层封装**：封装 Axios 实例，配置请求/响应拦截器统一注入 Token、解包 `BizResult` 与集中弹窗报错，各页面无需重复处理异常，接口层单函数平均代码量压缩至 **2-3 行**
- **逻辑复用**：抽象 `useDebounce`（搜索防抖）、`usePage`（分页状态管理）等 4 个自定义 Composable，复用高频逻辑，组件内样板代码减少 **50%+**
- **数据可视化**：首页接入 ECharts 注册趋势折线图与角色分布饼图，组件内完整实现实例化、窗口 `resize` 自适应、`onUnmounted` 销毁释放实例 + 移除事件监听，**避免内存泄漏**
- **前后端闭环**：后端使用 Express + JWT 搭建鉴权闭环（学习用途实现），独立输出《接口说明文档》9 个接口，规范请求/响应结构，形成前后端联调契约
- **部署上线**：项目已通过 GitHub Pages 完成部署，可在线访问
